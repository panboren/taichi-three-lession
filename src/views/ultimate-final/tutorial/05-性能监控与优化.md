# 教程5: 性能监控与优化 - 精准控制性能

## 概述

本教程讲解如何使用桥接器的性能监控功能,以及各种优化技巧,帮助您精准控制和提升性能。

## 性能监控指标

桥接器提供以下性能指标:

| 指标 | 说明 | 单位 |
|------|------|------|
| `fps` | 实时帧率 | FPS |
| `avgFps` | 平均帧率 | FPS |
| `minFps` / `maxFps` | 最小/最大帧率 | FPS |
| `avgFrameTime` | 平均帧时间 | ms |
| `avgTransferTime` | 平均传输时间 | ms |
| `avgComputeTime` | 平均计算时间 | ms |
| `frameTimeStdDev` | 帧时间标准差 | ms |
| `dataTransferSize` | 每帧数据大小 | bytes |
| `dataThroughput` | 数据吞吐量 | MB/s |
| `stabilityScore` | 稳定性评分 | 0-1 |
| `dropFrameCount` | 丢帧数 | count |
| `predictedFps` | 预测帧率 | FPS |
| `predictedTrend` | 性能趋势 | enum |

## 实例1: 基础性能监控

```typescript
import * as THREE from 'three'
import { UltimateTaichiThreeBridge, UltimatePerformanceMetrics } from '../js/UltimateTaichiThreeBridge'

// 创建场景
const scene = new THREE.Scene()
const camera = new THREE.PerspectiveCamera(75, window.innerWidth / window.innerHeight, 0.1, 1000)
const renderer = new THREE.WebGLRenderer({ antialias: false })  // 禁用抗锯齿提升性能
renderer.setSize(window.innerWidth, window.innerHeight)
document.body.appendChild(renderer.domElement)

camera.position.z = 5

// 创建 Taichi 引擎
const taichiEngine = {
  async getPixelData() {
    const width = 512
    const height = 512
    const data = new Uint8Array(width * height * 4)
    const time = performance.now() * 0.001

    for (let y = 0; y < height; y++) {
      for (let x = 0; x < width; x++) {
        const i = (y * width + x) * 4
        const nx = x / width - 0.5
        const ny = y / height - 0.5
        const wave = Math.sin(nx * 10 + time) * Math.cos(ny * 10 + time)

        data[i] = Math.floor(127 + 127 * wave)
        data[i + 1] = Math.floor(127 + 127 * Math.sin(time))
        data[i + 2] = Math.floor(127 + 127 * Math.cos(time))
        data[i + 3] = 255
      }
    }
    return data.buffer
  }
}

// 创建桥接器,启用性能监控
const bridge = new UltimateTaichiThreeBridge({
  renderer,
  scene,
  camera,
  width: 512,
  height: 512,
  mode: 'canvas-texture',
  performance: {
    enabled: true,                    // 启用监控
    updateInterval: 500,              // 500ms 更新一次
    enablePrediction: true,           // 启用性能预测
    historySize: 120,                 // 保留120帧历史
    enableProfiling: false            // 禁用详细分析(节省性能)
  },
  onPerformanceUpdate: (metrics: UltimatePerformanceMetrics) => {
    console.log('=== 性能报告 ===')
    console.log(`FPS: ${metrics.fps.toFixed(1)} (平均: ${metrics.avgFps.toFixed(1)})`)
    console.log(`帧时间: ${metrics.avgFrameTime.toFixed(2)}ms`)
    console.log(`传输时间: ${metrics.avgTransferTime.toFixed(2)}ms`)
    console.log(`稳定性: ${(metrics.stabilityScore * 100).toFixed(1)}%`)
    console.log(`丢帧: ${metrics.dropFrameCount}/${metrics.frameCount}`)
    console.log(`数据吞吐: ${metrics.dataThroughput.toFixed(2)} MB/s`)
    console.log(`预测 FPS: ${metrics.predictedFps.toFixed(1)}`)
    console.log(`趋势: ${metrics.predictedTrend}`)
    console.log(`分辨率: ${metrics.currentResolution.width}x${metrics.currentResolution.height}`)
    console.log('================')
  }
})

await bridge.init(taichiEngine)

// 渲染循环
function animate(time: number) {
  requestAnimationFrame(animate)
  bridge.step(time)
  renderer.render(scene, camera)
}

animate(0)
```

## 实例2: 性能图表可视化

```typescript
// 创建性能监控面板
class PerformancePanel {
  private container: HTMLElement
  private fpsChart: HTMLCanvasElement
  private transferChart: HTMLCanvasElement
  private fpsHistory: number[] = []
  private transferHistory: number[] = []

  constructor() {
    this.container = document.createElement('div')
    this.container.style.position = 'fixed'
    this.container.style.top = '10px'
    this.container.style.left = '10px'
    this.container.style.background = 'rgba(0,0,0,0.85)'
    this.container.style.color = '#fff'
    this.container.style.padding = '15px'
    this.container.style.borderRadius = '8px'
    this.container.style.fontSize = '12px'
    this.container.style.fontFamily = 'monospace'
    this.container.style.zIndex = '1000'

    // 创建 FPS 图表
    this.fpsChart = document.createElement('canvas')
    this.fpsChart.width = 200
    this.fpsChart.height = 100
    this.fpsChart.style.marginTop = '10px'
    this.fpsChart.style.border = '1px solid #333'

    // 创建传输时间图表
    this.transferChart = document.createElement('canvas')
    this.transferChart.width = 200
    this.transferChart.height = 60
    this.transferChart.style.marginTop = '5px'
    this.transferChart.style.border = '1px solid #333'

    this.container.innerHTML = `
      <div style="margin-bottom:10px;font-weight:bold;color:#00ff88;">性能监控</div>
      <div id="metrics-text"></div>
    `
    this.container.appendChild(this.fpsChart)
    this.container.appendChild(this.transferChart)
    document.body.appendChild(this.container)
  }

  // 更新指标
  update(metrics: UltimatePerformanceMetrics) {
    // 更新历史
    this.fpsHistory.push(metrics.fps)
    this.transferHistory.push(metrics.avgTransferTime)

    // 限制历史长度
    if (this.fpsHistory.length > 100) {
      this.fpsHistory.shift()
      this.transferHistory.shift()
    }

    // 更新文本
    const textDiv = document.getElementById('metrics-text')!
    const stabilityColor = metrics.stabilityScore > 0.8 ? '#00ff88' :
                          metrics.stabilityScore > 0.5 ? '#ffaa00' : '#ff4444'

    textDiv.innerHTML = `
      <div>FPS: <span style="color:${this.getFpsColor(metrics.fps)}">${metrics.fps.toFixed(1)}</span></div>
      <div>平均: ${metrics.avgFps.toFixed(1)} / 最低: ${metrics.minFps.toFixed(1)}</div>
      <div>传输: ${metrics.avgTransferTime.toFixed(2)}ms / 吞吐: ${metrics.dataThroughput.toFixed(1)}MB/s</div>
      <div>稳定性: <span style="color:${stabilityColor}">${(metrics.stabilityScore * 100).toFixed(1)}%</span></div>
      <div>趋势: ${this.getTrendEmoji(metrics.predictedTrend)} ${metrics.predictedTrend}</div>
      <div>分辨率: ${metrics.currentResolution.width}x${metrics.currentResolution.height}</div>
    `

    // 绘制图表
    this.drawChart(this.fpsChart, this.fpsHistory, 120, '#00ff88')
    this.drawChart(this.transferChart, this.transferHistory, 20, '#ffaa00')
  }

  // 绘制图表
  private drawChart(canvas: HTMLCanvasElement, data: number[], max: number, color: string) {
    const ctx = canvas.getContext('2d')!
    const width = canvas.width
    const height = canvas.height

    // 清除
    ctx.fillStyle = 'rgba(0,0,0,0.8)'
    ctx.fillRect(0, 0, width, height)

    // 绘制网格
    ctx.strokeStyle = '#333'
    ctx.lineWidth = 1
    for (let i = 0; i <= 4; i++) {
      const y = (i / 4) * height
      ctx.beginPath()
      ctx.moveTo(0, y)
      ctx.lineTo(width, y)
      ctx.stroke()
    }

    // 绘制数据线
    if (data.length > 1) {
      ctx.strokeStyle = color
      ctx.lineWidth = 2
      ctx.beginPath()

      data.forEach((value, i) => {
        const x = (i / (data.length - 1)) * width
        const y = height - (value / max) * height

        if (i === 0) ctx.moveTo(x, y)
        else ctx.lineTo(x, y)
      })

      ctx.stroke()
    }
  }

  // FPS 颜色
  private getFpsColor(fps: number): string {
    if (fps >= 55) return '#00ff88'
    if (fps >= 30) return '#ffaa00'
    return '#ff4444'
  }

  // 趋势表情
  private getTrendEmoji(trend: string): string {
    switch (trend) {
      case 'improving': return '📈'
      case 'stable': return '➡️'
      case 'degrading': return '📉'
      default: return '❓'
    }
  }
}

// 使用性能面板
const panel = new PerformancePanel()

bridge.options.onPerformanceUpdate = (metrics) => {
  panel.update(metrics)
}
```

## 实例3: 自动优化策略

```typescript
// 自动优化控制器
class AutoOptimizer {
  private bridge: UltimateTaichiThreeBridge
  private modeIndex: number = 0
  private modes: string[] = [
    'webgpu-shared-texture',
    'transferable-imagebitmap',
    'webgl2-pbo',
    'offscreen-imagebitmap',
    'canvas-texture'
  ]

  constructor(bridge: UltimateTaichiThreeBridge) {
    this.bridge = bridge
  }

  // 检查是否需要优化
  async checkAndOptimize(metrics: UltimatePerformanceMetrics): Promise<void> {
    const targetFps = this.bridge.options.targetFps

    // 性能不足时降级
    if (metrics.avgFps < targetFps * 0.8) {
      await this.downgradeMode()
    }

    // 性能充足时尝试升级
    if (metrics.avgFps > targetFps * 1.2 && metrics.stabilityScore > 0.9) {
      await this.upgradeMode()
    }

    // 调整分辨率
    await this.adjustResolution(metrics)
  }

  // 降级模式
  private async downgradeMode(): Promise<void> {
    if (this.modeIndex < this.modes.length - 1) {
      this.modeIndex++
      const newMode = this.modes[this.modeIndex]
      console.log(`性能不足,降级到: ${newMode}`)
      await this.bridge.switchMode(newMode as any)
    }
  }

  // 升级模式
  private async upgradeMode(): Promise<void> {
    if (this.modeIndex > 0) {
      this.modeIndex--
      const newMode = this.modes[this.modeIndex]
      console.log(`性能充足,升级到: ${newMode}`)
      await this.bridge.switchMode(newMode as any)
    }
  }

  // 调整分辨率
  private async adjustResolution(metrics: UltimatePerformanceMetrics): Promise<void> {
    const targetFps = this.bridge.options.targetFps
    const currentRes = metrics.currentResolution
    let newWidth = currentRes.width
    let newHeight = currentRes.height

    // 性能不足,降低分辨率
    if (metrics.avgFps < targetFps * 0.9) {
      newWidth = Math.max(256, Math.floor(newWidth * 0.9))
      newHeight = Math.max(256, Math.floor(newHeight * 0.9))
    }

    // 性能充足,提高分辨率
    if (metrics.avgFps > targetFps * 1.1) {
      newWidth = Math.min(2048, Math.floor(newWidth * 1.1))
      newHeight = Math.min(2048, Math.floor(newHeight * 1.1))
    }

    if (newWidth !== currentRes.width || newHeight !== currentRes.height) {
      console.log(`调整分辨率: ${currentRes.width}x${currentRes.height} -> ${newWidth}x${newHeight}`)
      await this.bridge.setSize(newWidth, newHeight)
    }
  }
}

const optimizer = new AutoOptimizer(bridge)

bridge.options.onPerformanceUpdate = async (metrics) => {
  await optimizer.checkAndOptimize(metrics)
}
```

## 实例4: 性能基准测试

```typescript
// 性能基准测试工具
class PerformanceBenchmark {
  private bridge: UltimateTaichiThreeBridge
  private results: any[] = []

  constructor(bridge: UltimateTaichiThreeBridge) {
    this.bridge = bridge
  }

  // 运行基准测试
  async runBenchmark(duration: number = 5000): Promise<any> {
    console.log(`开始基准测试,持续 ${duration}ms...`)

    const startTime = performance.now()
    const samples: UltimatePerformanceMetrics[] = []

    // 收集性能数据
    const collectData = setInterval(() => {
      samples.push(this.bridge.getMetrics())
    }, 100)

    // 等待测试完成
    await new Promise(resolve => setTimeout(resolve, duration))
    clearInterval(collectData)

    // 分析结果
    const result = this.analyzeResults(samples)
    this.results.push(result)

    console.log('基准测试完成:')
    console.table(result)

    return result
  }

  // 分析结果
  private analyzeResults(samples: UltimatePerformanceMetrics[]): any {
    const avgFps = samples.reduce((sum, m) => sum + m.fps, 0) / samples.length
    const avgFrameTime = samples.reduce((sum, m) => sum + m.avgFrameTime, 0) / samples.length
    const avgTransferTime = samples.reduce((sum, m) => sum + m.avgTransferTime, 0) / samples.length
    const minFps = Math.min(...samples.map(m => m.fps))
    const maxFps = Math.max(...samples.map(m => m.fps))
    const avgStability = samples.reduce((sum, m) => sum + m.stabilityScore, 0) / samples.length
    const totalDrops = samples.reduce((sum, m) => sum + m.dropFrameCount, 0)

    return {
      avgFps: avgFps.toFixed(2),
      minFps: minFps.toFixed(2),
      maxFps: maxFps.toFixed(2),
      avgFrameTime: avgFrameTime.toFixed(2) + 'ms',
      avgTransferTime: avgTransferTime.toFixed(2) + 'ms',
      stability: (avgStability * 100).toFixed(1) + '%',
      droppedFrames: totalDrops,
      mode: samples[0].mode,
      resolution: `${samples[0].currentResolution.width}x${samples[0].currentResolution.height}`
    }
  }

  // 对比不同模式
  async compareModes(modes: string[]): Promise<void> {
    console.log('对比不同传输模式...')
    const comparison = []

    for (const mode of modes) {
      // 创建新桥接器
      const bridge = new UltimateTaichiThreeBridge({
        renderer,
        scene,
        camera,
        width: 512,
        height: 512,
        mode: mode as any,
        autoDetectMode: false,
        performance: { enabled: true, updateInterval: 500 }
      })

      await bridge.init(taichiEngine)

      // 运行测试
      const benchmark = new PerformanceBenchmark(bridge)
      const result = await benchmark.runBenchmark(3000)

      comparison.push({
        mode,
        ...result
      })

      bridge.dispose()
    }

    console.log('模式对比结果:')
    console.table(comparison)
  }
}

// 运行基准测试
const benchmark = new PerformanceBenchmark(bridge)

// 测试当前模式
await benchmark.runBenchmark(5000)
```

## 实例5: 性能预警系统

```typescript
// 性能预警系统
class PerformanceAlertSystem {
  private bridge: UltimateTaichiThreeBridge
  private alertContainer: HTMLElement

  constructor(bridge: UltimateTaichiThreeBridge) {
    this.bridge = bridge
    this.createAlertContainer()
  }

  private createAlertContainer(): void {
    this.alertContainer = document.createElement('div')
    this.alertContainer.style.position = 'fixed'
    this.alertContainer.style.top = '10px'
    this.alertContainer.style.right = '10px'
    this.alertContainer.style.zIndex = '9999'
    this.alertContainer.style.maxWidth = '300px'
    document.body.appendChild(this.alertContainer)
  }

  // 检查性能状态
  checkPerformance(metrics: UltimatePerformanceMetrics): void {
    // FPS 过低预警
    if (metrics.fps < 30) {
      this.showAlert('FPS过低', `当前FPS: ${metrics.fps.toFixed(1)},建议降低分辨率`, 'error')
    }
    // FPS 偏低警告
    else if (metrics.fps < 45) {
      this.showAlert('FPS偏低', `当前FPS: ${metrics.fps.toFixed(1)},考虑优化设置`, 'warning')
    }

    // 稳定性差警告
    if (metrics.stabilityScore < 0.6) {
      this.showAlert('稳定性差', `稳定性: ${(metrics.stabilityScore * 100).toFixed(1)}%,检查系统负载`, 'warning')
    }

    // 性能下降预警
    if (metrics.predictedTrend === 'degrading') {
      this.showAlert('性能下降', `FPS趋势下降,将${metrics.predictedFps.toFixed(1)} → 预测值`, 'info')
    }
  }

  // 显示警告
  private showAlert(title: string, message: string, type: 'error' | 'warning' | 'info'): void {
    const colors = {
      error: { bg: 'rgba(255,68,68,0.9)', border: '#ff4444' },
      warning: { bg: 'rgba(255,170,0,0.9)', border: '#ffaa00' },
      info: { bg: 'rgba(0,136,255,0.9)', border: '#0088ff' }
    }

    const alert = document.createElement('div')
    alert.style.background = colors[type].bg
    alert.style.border = `2px solid ${colors[type].border}`
    alert.style.color = '#fff'
    alert.style.padding = '10px 15px'
    alert.style.marginBottom = '10px'
    alert.style.borderRadius = '5px'
    alert.style.boxShadow = '0 2px 10px rgba(0,0,0,0.3)'
    alert.style.animation = 'slideDown 0.3s ease-out'
    alert.innerHTML = `
      <div style="font-weight:bold;margin-bottom:5px;">${title}</div>
      <div style="font-size:11px;">${message}</div>
    `

    // 添加动画样式
    if (!document.getElementById('alert-styles')) {
      const style = document.createElement('style')
      style.id = 'alert-styles'
      style.textContent = `
        @keyframes slideDown {
          from { opacity: 0; transform: translateY(-20px); }
          to { opacity: 1; transform: translateY(0); }
        }
      `
      document.head.appendChild(style)
    }

    this.alertContainer.appendChild(alert)

    // 3秒后移除
    setTimeout(() => {
      alert.style.opacity = '0'
      alert.style.transition = 'opacity 0.3s'
      setTimeout(() => alert.remove(), 300)
    }, 3000)
  }
}

const alertSystem = new PerformanceAlertSystem(bridge)

bridge.options.onPerformanceUpdate = (metrics) => {
  alertSystem.checkPerformance(metrics)
}
```

## 性能优化技巧

### 1. Three.js 渲染器优化

```typescript
const renderer = new THREE.WebGLRenderer({
  antialias: false,              // 禁用抗锯齿
  powerPreference: 'high-performance',  // 高性能模式
  preserveDrawingBuffer: false,  // 不保留缓冲区
  stencil: false,                // 不需要模板缓冲
  depth: true                    // 需要深度测试
})

renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2))  // 限制像素比
```

### 2. 纹理优化

```typescript
// 在桥接器配置中
{
  textureLinear: false,          // 使用临近采样(性能更好)
```

### 3. 传输模式选择

- **最佳性能**: `transferable-imagebitmap` 或 `webgpu-shared-texture`
- **最佳兼容**: `canvas-texture`
- **平衡选择**: `webgl2-pbo`
