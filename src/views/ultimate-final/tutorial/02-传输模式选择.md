# 教程2: 传输模式选择 - 从简单到高级

## 概述

桥接器提供7种传输模式,从最兼容到最性能优化。本教程讲解如何选择和使用不同的传输模式。

## 传输模式对比

| 模式 | 性能 | 兼容性 | 使用场景 | 代码 |
|------|------|--------|----------|------|
| `webgpu-shared-texture` | ⭐⭐⭐⭐⭐ | ⭐ | Chrome 113+ | WebGPU 零拷贝 |
| `transferable-imagebitmap` | ⭐⭐⭐⭐ | ⭐⭐⭐⭐ | 现代浏览器 | 零拷贝线程传输 |
| `offscreen-worker` | ⭐⭐⭐⭐ | ⭐⭐⭐ | 支持Worker | 后台渲染 |
| `webgl2-pbo` | ⭐⭐⭐ | ⭐⭐⭐⭐ | WebGL2 | 异步上传 |
| `offscreen-imagebitmap` | ⭐⭐⭐ | ⭐⭐⭐⭐ | OffscreenCanvas | 标准传输 |
| `canvas-texture` | ⭐⭐ | ⭐⭐⭐⭐⭐ | 所有浏览器 | 兼容性最好 |
| `pixel-buffer` | ⭐ | ⭐⭐⭐⭐⭐ | 所有浏览器 | 精确控制 |

## 模式1: CanvasTexture (最兼容)

**适用场景**: 需要最大兼容性,性能要求不高

```typescript
const bridge = new UltimateTaichiThreeBridge({
  renderer,
  scene,
  camera,
  width: 512,
  height: 512,
  mode: 'canvas-texture',
  autoDetectMode: false
})

await bridge.init(taichiEngine)
```

**原理**: 使用 HTMLCanvasElement,直接绑定到 CanvasTexture

**性能**: ~20-30 FPS @ 512x512

---

## 模式2: OffscreenCanvas + ImageBitmap

**适用场景**: 需要更好性能,支持 OffscreenCanvas

```typescript
const bridge = new UltimateTaichiThreeBridge({
  renderer,
  scene,
  camera,
  width: 512,
  height: 512,
  mode: 'offscreen-imagebitmap',
  offscreen: {
    enabled: true,
    enableTransferable: false  // 不使用 Transferable
  },
  autoDetectMode: false
})

await bridge.init(taichiEngine)
```

**原理**: 使用 OffscreenCanvas 和 createImageBitmap

**性能**: ~40-50 FPS @ 512x512

---

## 模式3: WebGL2 PBO (异步上传)

**适用场景**: WebGL2 环境,需要异步传输优化

```typescript
const bridge = new UltimateTaichiThreeBridge({
  renderer,
  scene,
  camera,
  width: 512,
  height: 512,
  mode: 'webgl2-pbo',
  enableWebGL2PBO: true,
  pboBufferSize: 16,  // 16MB PBO 缓冲
  autoDetectMode: false
})

await bridge.init(taichiEngine)
```

**原理**: 使用 WebGL2 Pixel Buffer Object 异步上传纹理数据

**性能**: ~50-60 FPS @ 512x512

**PBO 优势**:
- 异步传输,不阻塞主线程
- 利用 GPU DMA 直接传输
- 减少 CPU-GPU 同步等待

## 模式4: Transferable ImageBitmap (零拷贝)

**适用场景**: 现代浏览器,追求最佳性能

```typescript
const bridge = new UltimateTaichiThreeBridge({
  renderer,
  scene,
  camera,
  width: 512,
  height: 512,
  mode: 'transferable-imagebitmap',
  offscreen: {
    enabled: true,
    enableTransferable: true  // 使用 Transferable Objects
  },
  autoDetectMode: false
})

await bridge.init(taichiEngine)
```

**原理**: 使用 Transferable Objects 零拷贝传输 ImageBitmap

**性能**: ~70-80 FPS @ 512x512

**Transferable 优势**:
- 零拷贝传输,不复制数据
- 线程间高效传递
- 浏览器原生优化

## 模式5: Offscreen Worker (后台渲染)

**适用场景**: 复杂计算,需要多线程

```typescript
// 首先创建 Worker 脚本
const workerScript = `
  let canvas = null
  let ctx = null

  self.onmessage = async (e) => {
    const { type, data } = e.data

    if (type === 'init') {
      canvas = e.data.canvas
      ctx = canvas.getContext('2d')
    } else if (type === 'render') {
      if (ctx && data) {
        ctx.putImageData(data, 0, 0)
      }
      self.postMessage({ type: 'renderComplete' })
    }
  }
`

// 创建 Worker URL
const workerUrl = URL.createObjectURL(
  new Blob([workerScript], { type: 'application/javascript' })
)

const bridge = new UltimateTaichiThreeBridge({
  renderer,
  scene,
  camera,
  width: 512,
  height: 512,
  mode: 'offscreen-worker',
  offscreen: {
    enabled: true,
    enableWorker: true,
    workerScript: workerUrl
  },
  autoDetectMode: false
})

await bridge.init(taichiEngine)
```

**原理**: 使用 Web Worker 在后台线程渲染

**性能**: ~60-70 FPS @ 512x512

**Worker 优势**:
- 不阻塞主线程
- 并行计算
- 更流畅的 UI 响应

## 模式6: WebGPU 共享纹理 (最高性能)

**适用场景**: Chrome 113+, 需要极致性能

```typescript
const bridge = new UltimateTaichiThreeBridge({
  renderer,
  scene,
  camera,
  width: 512,
  height: 512,
  mode: 'webgpu-shared-texture',
  webgpu: {
    enabled: true,
    enableSharedTexture: true,
    sharedTextureUsage:
      GPUTextureUsage.RENDER_ATTACHMENT |
      GPUTextureUsage.TEXTURE_BINDING,
    powerPreference: 'high-performance'
  },
  autoDetectMode: false
})

await bridge.init(taichiEngine)
```

**原理**: 使用 WebGPU GPU-GPU 零拷贝共享纹理

**性能**: ~90+ FPS @ 512x512

**WebGPU 优势**:
- GPU-GPU 直接共享,零 CPU 参与
- 最小的传输开销
- 现代图形 API

---

## 模式7: 像素缓冲 (精确控制)

**适用场景**: 需要精确控制数据格式和传输

```typescript
const bridge = new UltimateTaichiThreeBridge({
  renderer,
  scene,
  camera,
  width: 512,
  height: 512,
  mode: 'pixel-buffer',
  pixelBuffer: {
    width: 512,
    height: 512,
    dataType: 'uint8',  // 或 'uint16', 'float32'
    data: new Uint8Array(512 * 512 * 4)  // 预分配
  },
  autoDetectMode: false
})

await bridge.init(taichiEngine)
```

**原理**: 直接操作像素数据缓冲区

**性能**: ~15-20 FPS @ 512x512

**适用**:
- 精确控制数据格式
- 自定义数据处理
- 非图像数据(如深度、法线)

## 自动模式检测

让桥接器自动选择最优模式:

```typescript
const bridge = new UltimateTaichiThreeBridge({
  renderer,
  scene,
  camera,
  width: 512,
  height: 512,
  autoDetectMode: true,  // 自动检测
  enableModeFallback: true,  // 启用降级
  fallbackThreshold: 45,  // FPS < 45 时降级
  upgradeThreshold: 55,  // FPS > 55 时升级
  onModeChange: (from, to) => {
    console.log(`模式切换: ${from} -> ${to}`)
  }
})

await bridge.init(taichiEngine)
```

**自动检测优先级**:
1. WebGPU SharedTexture
2. Transferable ImageBitmap
3. Offscreen Worker
4. WebGL2 PBO
5. Offscreen ImageBitmap
6. CanvasTexture

## 性能对比测试

```typescript
async function benchmarkModes() {
  const modes = [
    'canvas-texture',
    'offscreen-imagebitmap',
    'webgl2-pbo',
    'transferable-imagebitmap',
    'offscreen-worker'
  ]

  const results = []

  for (const mode of modes) {
    // 创建新桥接器
    const bridge = new UltimateTaichiThreeBridge({
      renderer,
      scene,
      camera,
      width: 512,
      height: 512,
      mode,
      autoDetectMode: false
    })

    await bridge.init(taichiEngine)

    // 运行 5 秒
    const startTime = performance.now()
    await new Promise(resolve => setTimeout(resolve, 5000))

    // 获取性能指标
    const metrics = bridge.getMetrics()
    results.push({
      mode,
      avgFps: metrics.avgFps,
      avgTransferTime: metrics.avgTransferTime
    })

    bridge.dispose()
  }

  // 输出结果
  console.table(results)
}

// 运行测试
benchmarkModes()
```
